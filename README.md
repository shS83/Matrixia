# Matrixia

I Was unsatisfied with the LLM version of the Matrix Rain effect, hence made a better one by hand.

Now as a bonus, there is a KDE -wallpaper installer in matrixia-wallpaper-1.0.2. Just run ./install.sh there and
then modify the configuration values in ~/.config/matrixia.conf to get the wanted outcome. 

Then select Desktop and Wallpaper in KDE and Wallpaper type: Matrixia and it should run as intended.

I strongly suggest installing VL-Gothic-Regular.ttf to system fonts if you're going to run it as wallpaper. 
Otherwise it may fallback to default serif font.
